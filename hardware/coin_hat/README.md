# Coin sorter HAT+ — rev 0 sketch

KiCad 8 starting point for a Pi 5 HAT+ that carries the whole motion side of the
sorter: 12 V in, buck to 5 V for the Pi, a Raspberry Pi Pico, three StepStick
sockets (TMC2209 or A4988, selected by solder jumpers), switched 12 V outputs, and the small stuff (LED ring level
shifter, home switches, coin sensor, HAT+ ID EEPROM). It stands off the Pi on
the 40-pin header only; 33.5 mm of the board overhangs past the Pi's header edge
so the drivers, jack and buck sit over nothing.

Generated by a script, so it is a *netlist with symbols placed on a sheet*, not
a drawn schematic: every pin carries a global label and the parts are grouped by
function. Redraw with wires or leave it — KiCad is happy either way.

## Files

- `coin_hat.kicad_pro` / `coin_hat.kicad_sch` — open this. Symbols are embedded;
  footprints point at the stock KiCad 8 libraries. **Tools → Update PCB from
  Schematic** pulls all footprints into the board.
- `coin_hat.kicad_pcb` — 65 × 90 outline with the HAT+ hole pattern and header
  position at the Pi end, and dashed placement zones with notes on
  `User.Comments`. No footprints yet (see above).

## Pin map (Pico)

| Function | Pins | Notes |
|---|---|---|
| Pi link | GP0 TX / GP1 RX (UART0) | Pi GPIO14/15, `/dev/ttyAMA0`, `dtparam=uart0=on`. REPL stays on USB. |
| Belt | STEP GP2, DIR GP3, EN GP4 | unchanged from `firmware/main.py` |
| Diverter | STEP GP6, DIR GP7, EN GP8 | 17HS4023, TMC UART addr 2 |
| Feeder | STEP GP18, DIR GP19, EN GP22 | TMC UART addr 1 (belt is 0) |
| TMC UART | GP20 TX via 1 k, GP21 RX | single-wire bus shared by all three |
| Home switches | GP10 diverter, GP11 feeder | to GND, internal pull-ups |
| Coin sensor | GP5 | 3-pin XH |
| Key light / aux MOSFET | GP14 / GP15 | AO3400, flyback diode, 2-pin terminals |
| LED ring | GP16 → 74AHCT1G125 → 5 V data | 3-pin XH |
| VMOT sense | GP28 | 100 k / 15 k: 12 V → 1.57 V |
| Aux header | GP9, GP17, GP12/13 (I²C), GP26/27 (ADC) | plus 3V3/GND |

Pi resets the Pico with **GPIO17 high** through Q3 pulling RUN low. Active-high
on purpose: GPIO17 defaults to pull-down at boot, so an unconfigured Pi leaves
the Pico running. `pinctrl set 17 op dh; sleep 0.1; pinctrl set 17 dl` replaces
the USB DTR-toggle that relaunches `main.py` today.

## Power

Jack → F1 (mini blade) → +12 V bus → StepSticks (100 µF each), switched outputs,
and U5 (12→5 V, 5 A module) → +5 V → Pi header pins 2/4 and Pico VSYS through D1.
Feeding a Pi 5 over the header skips USB-PD, so set `usb_max_current_enable=1`
if USB peripherals need more than 600 mA. Size F1 to the real load (Pi 5 up to
~2.3 A at 12 V, plus motors).

## Verify before ordering

- TMC2209 breakout pin order (the 16-pin socket varies between makers; DIAG /
  INDEX are often extra pins outside it).
- Solder jumpers per driver socket (JPx1–JPx4) match the driver you fit:
  **TMC2209** — JPx3=A (UART on pin 4), JPx4=A (CLK→GND), JPx1/JPx2 = UART
  address (belt 00, feeder 10, diverter 01). **A4988** — JPx3=B (MS3 high),
  JPx4=B (RESET tied to SLEEP), JPx1+JPx2 closed = 1/16 step; set Vref =
  I × 8 × Rsense (0.40 V for 0.5 A with R100 sense resistors); heatsink.
- Buck module pin order — U5 is drawn as a generic 5-pin header.
- Header and hole positions against the official HAT+ mechanical drawing. The
  socket goes on the **bottom** side; pin 1 is drawn at (7.1, 39.54) in board
  coordinates with the Pi's header edge at y = 33.5.
- Header height vs the Pi 5 active cooler: use an extra-tall stacking header.
- Belt motor current rating (TMC2209 tops out around 2 A RMS).

## Firmware implications

Pin changes for the feeder (DIR/EN) and diverter (now STEP/DIR/EN, not a 4-wire
28BYJ-48), the Pi link moves from USB CDC to UART0, and current/hold settings
move from DIP switches to TMC UART writes. None of this changes the serial
protocol the Pi speaks.
